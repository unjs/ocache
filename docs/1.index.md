# Getting Started

ocache provides composable caching tools. It has no framework dependencies. It works with any runtime that supports the standard `Request` and `Response` APIs.

You can use two main tools:

- [`defineCachedFunction`](/functions) — adds TTL, stale-while-revalidate, integrity checks, and in-flight request deduplication to any async function.
- [`defineCachedHandler`](/handler) — adds full response caching to an HTTP handler. It supports `etag`, `304 Not Modified`, `Cache-Control`, and more.

## Quick Start

Wrap a function with `defineCachedFunction` to add TTL caching, stale-while-revalidate, and request deduplication:

```ts
import { defineCachedFunction } from "ocache";

const cachedFetch = defineCachedFunction(
  async (url: string) => {
    const res = await fetch(url);
    return res.json();
  },
  {
    maxAge: 60, // Cache for 60 seconds
    name: "api-fetch",
  },
);

// First call runs the function; subsequent calls return the cached result.
const data = await cachedFetch("https://api.example.com/data");
```

> [!TIP]
> All durations (`maxAge`, `staleMaxAge`, TTL) are in **seconds**.

By default, each cached function and handler uses its own in-memory `Map`. Nothing is shared unless you configure it. Use the [`storage` option](/storage) to provide Redis or another backend. You can also use this option to share one store between several functions or handlers.
